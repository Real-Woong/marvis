# 2026-07 · 비서 노릇 시작

두 달 쉬었다가 7월 말에 몰아서 손봤다. "저장해 주는 봇"에서 "먼저 말 거는
비서"로 넘어간 시기.

## 1. 기억이 사라지던 문제 (2026-07-28)

**증상.** 저장했다는 답을 받았는데 나중에 보면 없었다.

**원인.** 알림 루프와 메시지 핸들러가 같은 JSON 파일을 각자 읽고 각자 통째로
덮어썼다. 늦게 쓴 쪽이 이겼고, 그 사이에 들어온 것은 사라졌다.

**바꾼 것.**
- `bot.py` 한 덩어리를 `marvis/` 패키지로 쪼갰다 (`8bbd140`, 17개 파일).
  설정·저장·시간·음성·알림·핸들러가 각자 파일을 갖게 됐다.
- 저장 경로에 자물쇠를 걸었다 (`3efb679`). 읽고-고치고-쓰는 구간을 한 번에
  한 쪽만 지나가게 했다.

파일 하나에 다 넣은 대가를 여기서 치렀다. 다만 이때도 저장소는 여전히 JSON
파일이었고, 진짜 해결은 9월의 SQLite 이전이었다.

## 2. 아침 브리핑 (2026-07-28, `0b9c386`)

묻지 않아도 아침에 먼저 오늘 일정을 알려준다. 하루에 한 번만 보내야 해서
"오늘 보냈는가"를 저장소에 남긴다. 봇이 아침에 꺼져 있다가 오후에 켜지면
"좋은 아침입니다"가 오후 2시에 도착하는 문제가 있어, 예정 시각을 두 시간
넘겼으면 그날은 건너뛰도록 했다.

## 3. Siri로 손 안 대고 저장 (2026-07-28, `02e2e9f`, `b34d0a3`)

걸어가면서 떠오른 것을 텔레그램을 열어서 치는 건 이미 번거롭다. 로컬 웹훅을
열고 iPhone 단축어가 여기로 텍스트를 던지게 했다. "야 시리, 마비스에 적어줘"로
끝난다. 외부에 여는 포트라 비밀 토큰을 확인하고, 살아있는지 보는 `/health`만
인증 없이 뒀다.

## 4. 프로젝트 추적 (2026-07-30, `e608643` 외 8건)

일정만으로는 부족했다. 벌여 둔 프로젝트가 여럿인데 무엇이 어디까지 갔는지
기억나지 않았다. 프로젝트마다 상태(진행중/중단)와 다음 할 일을 두고, 아침
브리핑에 함께 실었다.

- "소곤.zip 다음할일은 유저정보 수집이야" 같은 평범한 말을 알아듣게 했다
  (`ff08eb8`). 명령어를 외우게 하면 안 쓰게 된다.
- 브리핑에서 특정 프로젝트를 빼고 넣는 것도 말로 했다 (`d04e4b6`).

**이때 넣었다가 9월에 되돌린 것:** 브리핑을 프로젝트당 한 통씩 쪼개 보냈다
(`a576b8a`). Siri "알림 읽어주기"가 긴 메시지를 요약해 버려서, 한 통에 한
프로젝트만 담아야 전부 읽어줬기 때문이다. 음성을 안 쓰게 되자 이 구조는
아침마다 알림 아홉 개를 쌓는 짐만 됐다 → 2026-09-10에 한 통으로 합쳤다.

읽어주기용으로 `BubbleBreak` 같은 이름에 띄어쓰기를 넣는 코드까지 있었다
(`86bb231`). 음성을 끄면서 같이 빠졌다.
