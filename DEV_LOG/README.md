## 쓰는 법

한 건을 마칠 때마다 한 파일. 파일명은 `YYYY-MM-DD-무엇.md`. 안에는 네 가지만
적는다.

1. **무엇이 문제였나** — 증상을, 겪은 그대로.
2. **왜 그랬나** — 코드의 어느 자리가 원인이었는지.
3. **무엇을 바꿨나** — 고른 방법과, 고르지 않은 방법.
4. **남은 것** — 알면서 안 고친 것.

증상 없이 "개선했다"만 적은 기록은 나중에 아무 쓸모가 없었다.
